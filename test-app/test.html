Gyakorlati teszt útmutató

init

Rövid utasítás: ellenőrizd, hogy az app elindul és betöltődik.

  • Futtasd az npm install parancsot.
  • Indítsd el az appet az npm run dev paranccsal.
  • Nyisd meg a Vite oldalt.
Várt eredmény: az alkalmazás a böngészőben sikeresen elindul, startup hiba nélkül.

App component

Rövid utasítás: ellenőrizd, hogy az App komponens megjelenik.

  • Nézd meg az App fájlt.
  • Győződj meg róla, hogy megjelenik az oldal.
Várt eredmény: az alkalmazás az App komponensen keresztül renderelődik, és megjelenik a képernyőn.

add component with property

Rövid utasítás: teszteld a Box komponenst.

  • Nyisd meg a Box komponenst.
  • Ellenőrizd, hogy a szöveg látszik.
Várt eredmény: minden Box példány helyesen megjeleníti a szövegét.

useState message

Rövid utasítás: ellenőrizd a message állapotot.

  • Importáld a useState hooket.
  • Jelenítsd meg az üzenetet.
Várt eredmény: az oldal megjelenít egy kezdeti üzenetet, amely az alkalmazás állapotában tárolódik.

click callback

Rövid utasítás: kattints a gombra és ellenőrizd az üzenetváltozást.

  • Kattints egy Box gombra.
  • Ellenőrizd, hogy Clicked! jelenik meg.
Várt eredmény: a gomb kattintása aktiválja a callbacket, és frissíti a megjelenített állapotüzenetet.
